## Skills demonstrated

PostgreSQL, credential-safe config.

**Data analysis:** KPIs, RFM segmentation, cohort/retention analysis, 38 SQL
business questions, window functions, CTEs, time intelligence.

**Machine learning:** feature engineering, temporal (out-of-time) validation,
model comparison + tuning, threshold trade-offs, interpretability.

**Production:** FastAPI, Streamlit, CI/CD, deployment docs, monitoring reports.

## Resume bullets (pick 3-4)

1. Cleaned and validated a 541,909-row retail dataset (→ 527,390 clean rows),
   establishing a single source of truth reconciled across Python and SQL.
2. Delivered RFM segmentation (4,339 customers) and 13-cohort retention
   analysis, verified 100% customer-by-customer between engines.
3. Built a customer-churn model (tuned logistic, C=0.1) evaluated on a held-out
   temporal window (W2 ROC-AUC 0.7332, recall 79.4%), flagging 1,114
   high-risk customers.
4. Wrapped the model in a FastAPI prediction service and a Streamlit demo, with
   automated CI and a data-quality monitoring report.
